# أرشيف تجربة مستكشف بوصلة

اعتُمدت التجربة في الإصدار المحلي الأول؛ الواجهة الوحيدة الآن في `web/` والتشغيل في `compass/`. الملفات Python هنا تمرر للأصل الرئيسي للتوافق مع الأوامر القديمة فقط.

التشغيل: `.venv\Scripts\python.exe -B -m compass launch`

العنوان الرئيسي: http://127.0.0.1:8620/

الوثائق التاريخية والتقارير باقية دون إعادة وصفها بأنها مراجعة للإصدار المدمج. النسخة السابقة الكاملة محفوظة محليًا في `backups/release-1-20261005/`، خارج Git. لا تنشر بيانات `data/` أو سجلات `runtime/`.
