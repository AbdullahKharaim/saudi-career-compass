# Saudi Labor Market Analytics

مشروع Portfolio لتحليل بيانات العاملين في القطاع الخاص حسب النشاط الاقتصادي والمنطقة الإدارية، من بيانات وزارة الموارد البشرية والتنمية الاجتماعية (الربعان الأول والثاني 2026).

## الحالة الحالية

- تجهيز البيانات وفحوص الجودة منفذان ومختبران، وينتظران مراجعة مستقلة.
- لم تُبنَ بعد اللوحة ولا الرسوم ولا التقرير، ولم تُحسب نسب التغير.
- المشروع غير جاهز للعرض.

المصادر وقواعد التجهيز: [docs/DATA-SOURCES.md](docs/DATA-SOURCES.md). النطاق: [PROJECT-PLAN.md](PROJECT-PLAN.md). الحالة التفصيلية: [PROJECT-STATUS.md](PROJECT-STATUS.md).

## التشغيل

من جذر المشروع (البيئة `.venv` موجودة وفق `requirements.txt`، ولا تحتاج تفعيلًا):

```powershell
# تجهيز البيانات (يتحقق أولًا ثم يكتب data/processed)
.venv\Scripts\python.exe -m labor_market.prepare

# الاختبارات
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## المخرجات (`data/processed`)

| الملف | المحتوى |
|---|---|
| `workers.csv` | 520 سجلًا: `year, quarter, region, economic_activity, workers, source_file`. الفراغ في `workers` يعني قيمة مفقودة وليس صفرًا. |
| `source_totals.csv` | 68 سجلًا لإجماليات المصدر (المناطق والأنشطة والإجمالي العام) للتحقق والمقامات، منفصلة عن التفاصيل. |
| `quality_report.json` | الهاشات والأحجام، والعدّ، والمفقودات بمواقعها، ومطابقة الإجماليات، والتحذيرات. |

لا تُكتب المخرجات إلا بعد نجاح كل التحققات. عند أي خطأ يتوقف التجهيز دون كتابة شيء.

## ما يتحقق منه التجهيز

- الحجم وSHA-256 لكل مصدر مقابل المسجل في الكود (`SOURCES` في `labor_market/prepare.py`)، وهو مطابق لـ`docs/DATA-SOURCES.md`.
- بنية CSV (صف العنوان، صف الرأس، 13 منطقة، 20 تصنيفًا، صف وعمود الإجمالي)، والأسماء غير المكررة والمتطابقة بين الملفين.
- الأعداد صحيحة غير سالبة أو فارغة؛ أي قيمة أخرى خطأ.
- مطابقة إجماليات المناطق والأنشطة والإجمالي العام بالقيم المتاحة، مع عدد المفقودات بجانب كل مطابقة.

## حدود مهمة

- المفقودات ثلاث: الربع الأول (الباحة ونجران) والربع الثاني (الباحة) في «الإدارة العامة والدفاع , الضمان الاجتماعي الالزامي». معنى الفراغات غير محسوم.
- نجاح المطابقة مع وجود مفقودات لا يعني اكتمال البيانات.
- «تحت المعالجة» تصنيف غير مفسر، محتفظ به كما هو.
- مقارنة بين ربعين فقط؛ لا تُجمع أعداد الربعين، ولا تُعد اتجاهًا طويل المدى.
