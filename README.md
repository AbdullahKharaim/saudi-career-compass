# بوصلة — Saudi Career Compass

إصدار محلي أول يساعد الطالب أو الخريج الذي يفكر في المجالات الرقمية على **اكتشاف اهتماماته → استكشاف مجال → تجربة نشاط متاح → اختيار أول خطوة تعلم**. يحوّل إطار المهارات المنشور في ملفات Excel وPDF إلى رحلة عربية قصيرة، مع فصل واضح بين المصدر الرسمي والاقتراحات التحريرية.

هذه أداة استكشاف وتقييم ذاتي، وليست اختبار ميول معتمدًا أو مطابقة مهنية مثبتة أو خدمة شواغر. اعتمد عبدالله التصميم الحالي خط أساس للإصدار الأول؛ لم تُنفذ دراسة استخدام بقياسات أو مستخدمين فعليين.

**حالة النشر (2026-10-05):** نُشرت النسخة العامة في [AbdullahKharaim/saudi-career-compass](https://github.com/AbdullahKharaim/saudi-career-compass) هي مجموعة كود قابلة للنشر، وليست الموقع العام أو نسخة كاملة قابلة للتشغيل بعد clone. استُبعد `web/assets/content.js` لاحتوائه على أسماء مهارات مقتبسة، و`compass/curated/digital_paths.json` لاحتوائه على نقل من PDF، وبيانات إطار المهارات ولقطاته وبعض تقارير واختبارات المصدر. كل الملفات محفوظة في النسخة المحلية؛ لا تُنشر قبل حسم الحقوق. [تدقيق النشر ومانع الاستضافة](docs/PUBLICATION-READINESS.md) يوضح الملفات والاعتماد على مسارات Python والخيارات التالية. لا يوجد حاليًا URL تطبيق HTTPS عام متحقق منه. تحقق الوصول العام دون تسجيل دخول ومطابقة الالتزام `e066009` والملفات الـ73 وبصماتها. تفاصيل الإثبات في وثيقة تدقيق النشر.

## التشغيل الرئيسي — النسخة المحلية الكاملة

من جذر المشروع في PowerShell، باستخدام البيئة الموجودة:

```powershell
.\.venv\Scripts\python.exe -B -m compass launch
```

**العنوان الرئيسي الوحيد: http://127.0.0.1:8620/**. يفتح من متصفح الجهاز نفسه. أبقِ المشغّل يعمل؛ Ctrl+C يوقفه. إن كان العنوان يعمل بالفعل فلا تبدأ نسخة أخرى. أمر `compass serve` بديل للخادم وحده دون تحديث تلقائي، وليس أمر التشغيل المعتاد.

حافظنا على أصل النموذج السابق 8620 ومفتاحيه `compassExplorer.v1` و`compassExplorer.motion`؛ تحديث الصفحة يعرض الإصدار الجديد مع تقدم المستكشف السابق. استخدام `localhost` أو منفذ آخر يعني تخزينًا مختلفًا عن `127.0.0.1:8620`.

## الإعداد على جهاز آخر — يتطلب النسخة الكاملة ومحتوى مصرحًا به

هذه الأوامر تخص النسخة الكاملة مع الملفات المستبعدة والحقوق المناسبة؛ نسخة GitHub وحدها لا تكفي لرحلة بوصلة. Python 3.13، ثم من جذر النسخة الكاملة:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B -m compass update
.\.venv\Scripts\python.exe -B -m compass launch
```

إن كانت البيئة والبيانات موجودتين فلا تعِد الإعداد. `compass update` يحتاج الشبكة وحقوق الاستخدام المحلي المناسبة ويجلب من الروابط الرسمية إلى مخزن محلي متحقق منه. رمز الخروج 0 نجاح، 1 تحديث جزئي مع آخر نسخة سليمة، 2 تعذر البناء. التشغيل في النسخة المحلية المجهزة الحالية يحتاج أمر `launch` وحده. من مخزن سليم موجود يمكن البناء بلا شبكة: `.\.venv\Scripts\python.exe -B -m compass build`. إن لم توجد بيانات سليمة يعرض التطبيق رسالة واضحة حتى يُنجز الجلب والبناء؛ لا تتضمن نسخة الكود أصول المهارات المقيدة.

## ما يعمل الآن

- 11 سؤالًا عن الأنشطة، مع «لا أعرف» وتخطٍّ، ومبررات لترتيب المجالات وتعادلها؛ دون تحويل المفقود إلى صفر أو نسبة جاهزية.
- 17 اسم مجال من 26 مدخلًا في قطاعي تقنية المعلومات والاتصالات. الأسماء المتكررة موضحة، والبحث يدعم صور الكتابة العربية ومرادفات تحريرية.
- أربع تجارب تفاعلية ببيانات خيالية: البيانات، البرمجيات، التصميم، والأمن السيبراني. المجالات الأخرى تقود إلى استكشاف مهارات البداية دون الادعاء بوجود تجربة.
- خطوة تعلم واحدة، وتقييم مختصر اختياري بسُلّم مبسط. تفضيل إيقاف الحركة وتقليلها، ودعم RTL ولوحة المفاتيح والعروض الضيقة.
- **«المزيد → حفظ ونقل»** لتنزيل واستعادة التقدم، بمعاينة وتأكيد ونسخة استرجاع قبل الاستبدال. من هناك التقييم الموسع الاختياري بسُلّم الإطار، والرحلات القديمة وتقارير HTML. منطق تعارض ملفات الرحلات القديمة بقي كما هو.
- لا تُدمج تقييمات السُّلّمين أو سجلات الاهتمامات تلقائيًا. ملفات الرحلات القديمة v1–v3 تستعيد التقييم الموسع فقط؛ ملف الإصدار v4 يحفظ المستكشف ومعه تقييم موسع منفصل إن وُجد. التفاصيل في [اتفاق الرحلة](docs/JOURNEY-FILE.md).
- إذا كان التقدم القديم في متصفحك على 8502، صدّره من ذلك الأصل ثم استورده من «حفظ ونقل» هنا؛ التطبيق لا يستطيع قراءة تخزين منفذ آخر. لم تُمس بيانات ذلك الأصل أثناء الدمج.

## التحديث المحلي المجدول

المشغّل يقدم الواجهة فورًا، ويفحص الموعد دون شبكة كل 30 دقيقة. يحاول التحقق من المصادر كل 168 ساعة من آخر نجاح، ويعيد المحاولة بعد 12 ساعة إذا فشل أو كان التحديث جزئيًا. ينفّذ ذلك **فقط أثناء تشغيل المشغّل والحاسوب**؛ ليس بيانات لحظية أو خدمة مستضافة دائمة.

الجلب والملفات والبناء متحقق منها، مع منع التداخل، ونشر مرحلي واعتماد ذري لزوج البيانات/البيان. عند فشل الشبكة أو التحقق أو البناء أو اعتماد النشر، تبقى آخر نسخة سليمة. تاريخ التحقق لا يعني تغير محتوى المصدر. مؤشر «إطار المهارات» يوضح الإصدار وتاريخ الملف والتحقق وحالة المشغّل. الفترات الجديدة أو المتعارضة تُعرض للمراجعة البشرية ولا تُعتمد آليًا.

السجلات المحلية: `runtime/launcher.log` و`runtime/state.json`؛ عند تشغيل منفصل مخفي تستخدم هذه النسخة أيضًا `runtime/launcher.out.txt` و`runtime/launcher.err.txt`. النشر في `web/published/`، مع آخر بناء محلي في `web/data/`. هذه البيانات والسجلات خارج Git.

## البنية والتقنيات

Python 3.13 للتحقق والجلب والتحويل والجدولة وخادم HTTP محلي؛ مكتبة Python القياسية لقراءة XLSX وPDF، وpandas لتحليل العاملين. الواجهة HTML وCSS وJavaScript بوحدات ES دون إطار أو خطوة بناء، وخط IBM Plex Sans Arabic محلي برخصة OFL. اختبارات المتصفح تستخدم Edge دون واجهة وCDP عبر `websockets` الموجودة في متطلبات المشروع.

- `web/index.html` و`web/assets/`: تجربة المستكشف الرئيسية.
- `web/assessment.html` و`assets/js/`: تقييم موسع ثانوي، ومنطق الرحلة القديم المتحقق منه، دون واجهة رئيسية منافسة.
- `compass/launcher.py`, `local_server.py`, `local_update.py`: التشغيل والتحديث المحلي.
- `compass/fetch.py`, `update.py`, `build.py`, `skills.py`, `pdf.py`, `odp.py`: خط المصادر وإثباتها؛ لا يُعاد تنفيذ حساباتها في الواجهة.
- `tests/`: الواجهة الرئيسية والمحتفظ بها، الحفظ والتوافق والمصادر والتحليل.
- `prototypes/compass-explorer/`: نقاط توافق للأوامر السابقة فقط؛ التطبيق الفعلي لم يعد هناك.

## التحقق

```powershell
$env:PYTHONIOENCODING='utf-8'
.\.venv\Scripts\python.exe -B -m compass verify --quick
.\.venv\Scripts\python.exe -B -m compass verify --deep
```

السريع: المستكشف والمحدث وحفظ الإصدار. العميق: جميع اختبارات `tests/` مرة واحدة، بما فيها التقييم القديم والتحليل والمصادر. الاختبارات بمخازن وملفات ومتصفحات وهمية معزولة؛ لا جلب حي ولا تغيير لتقدم المستخدم. يتطلب اختبار الواجهة Edge وبيانات إطار مبنية. ترميز UTF-8 إعداد لإخراج الطرفية العربية في Windows. النتائج الفعلية وحدود التحقق في [حالة المشروع](PROJECT-STATUS.md) و[سجل الإصدار](docs/RELEASE-INTEGRATION.md)، ولا تعني نجاح الاختبارات اعتمادًا للمطابقة المهنية أو سهولة الاستخدام البشرية.

## المصادر وما يمكن عرضه

المحتوى الرسمي: ملفات إطار المهارات القطاعية للقطاع الرقمي المنشورة ببوابة وزارة الموارد البشرية والتنمية الاجتماعية/مجلس مهارات القطاع الرقمي. العاملون: منصة البيانات المفتوحة، الربعان الأول والثاني 2026. الأسئلة وربطها بالمجالات ومهارات البداية والأمثلة والتمارين من إعداد بوصلة، ولا تُنسب بوصفها توصيات رسمية.

**إذن إعادة الاستخدام العام لملفات المهارات الثلاثة لم يُحسم في المشروع.** لا ترفع المصادر أو بيانات الواجهة المشتقة أو تقارير التقييم أو لقطات المحتوى الرسمي إلى مستودع عام أو موقع مستضاف. الاستبعاد من Git وحده لا يمنح إذن نشر. الأدلة لكل مصدر وتاريخ فحصها في [تدقيق النشر](docs/PUBLICATION-READINESS.md)؛ الدليل التفصيلي `docs/SOURCES-VERIFIED.md` محفوظ محليًا لاحتوائه نفسه على مقتطفات. لم تُنفذ مراجعة حقوق جديدة في هذا الإصدار.

لـCV يمكن وصف المشروع وبنيته وقراراته ونتائج التحقق دون نسخ الأصول المقيدة؛ العرض الحالي محلي. اللقطات التمثيلية أُعدت للمراجعة المحلية في `docs/review-screenshots/compass/release-1/` (مستبعدة من Git)، ولا تُعتبر جاهزة للنشر العام حتى حسم الحقوق. لا ترفع ملفات تقدم شخصية أيضًا.

## تحليل سوق العمل — مكون منفصل

لوحة Streamlit `app.py` بقيت لتحليل العاملين حسب المنطقة والنشاط بين ربعين. ليست جزءًا من اقتراح مجال أو خطوة تعلم، ولا تمثل الأعداد طلبًا على مهنة أو شواغر أو ملاءمة فردية.

```powershell
.\.venv\Scripts\python.exe -m labor_market.prepare
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

قواعد المفقودات والإجماليات والمصادر في [DATA-SOURCES](docs/DATA-SOURCES.md) و[ANALYSIS-CONTRACT](docs/ANALYSIS-CONTRACT.md). المفقود ليس صفرًا، و«تحت المعالجة» غير مفسر، وربعان لا يثبتان اتجاهًا طويل المدى.

## حدود الإصدار والمرحلة التالية

التغطية رقمية محدودة، والتجارب أربع فقط، والتقييم ذاتي. لا حسابات ولا استقبال لتقدم المستخدم في الخادم. رفع مجموعة الكود المراجعة لا يعني نشر التطبيق؛ لا توجد خدمة مستضافة دائمة أو تحديث مجدول خارجي. التصميم مقبول كخط أساس ولم تُحسم كل التفاصيل البصرية. تحسينات اختيارية مؤجلة: تجربة استخدام فعلية، قارئ شاشة، وتحسين التفاصيل البصرية من الملاحظات. الخطوة التالية الواحدة: تجربة عبدالله للرحلة المدمجة وتسجيل ملاحظات الإصدار التالي؛ لا توسع تغطية أو إعادة تصميم ضمن هذا التسليم.
