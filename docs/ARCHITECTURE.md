# بنية بوصلة — الإصدار المحلي الأول

## تجربة رئيسية واحدة

`web/index.html` يقدم مستكشف المجالات: الاهتمامات → المجال → التجربة المتاحة → أول خطوة تعلم. اعتمد عبدالله التصميم الحالي. التقييم المختصر اختياري، والتقييم الموسع والرحلات السابقة في `web/assessment.html` متاحة من «المزيد → حفظ ونقل». ليست هناك نسختان رئيسيتان للمستكشف؛ مجلد النموذج السابق يحتوي نقاط توافق تشغيل فقط، والنسخة السابقة الكاملة محفوظة خارج Git.

```text
روابط ومعرّفات رسمية صريحة
    → compass.update / fetch (تحقق، بصمات، آخر سليم، سجل)
    → data/sources/ (أصول محلية، غير مرفوعة)
    → compass.build (تحويل متحقق منه، دون تغيير حسابات المصدر)
    → مجلد مرحلي → web/published/generations/<id>/
    → web/published/current.json (خطوة اعتماد ذرية)
    → compass.local_server → web/ على 127.0.0.1:8620
    → حسابات JavaScript وتقدم في متصفح المستخدم وحده
```

## المكونات

| المسار | الدور |
|---|---|
| `compass/config.py` | سجل المصادر والروابط وشروط كل مصدر والفترات المعتمدة |
| `compass/fetch.py`, `update.py` | جلب متحقق منه، حفظ بالبصمة، مؤشرات آخر سليم، `If-None-Match`، اكتشاف الفترات دون اعتماد آلي |
| `compass/xlsx.py`, `skills.py`, `pdf.py`, `odp.py` | قراءة وتحويل والتحقق من الملفات والفترات؛ إصلاحات المصادر وPDF السابقة باقية |
| `compass/build.py` | البيانات الرسمية وبيان الإثبات؛ بناء إلى مجلد يحدده المستدعي |
| `compass/local_update.py` | جدولة محلية ومنع تداخل وبناء مرحلي واعتماد زوج البيانات/البيان بمؤشر جيل؛ يدعم النشر المسطح السابق دون إزالته |
| `compass/launcher.py` | خادم وخيط تحديث؛ الواجهة تبدأ فورًا ولا تنتظر الشبكة |
| `compass/local_server.py` | خادم 127.0.0.1 فقط؛ `web/` ومسارات بيانات للقراءة وحالة الحداثة؛ يحجب ملفات التشغيل والنشر الداخلية |
| `web/assets/model.js`, `content.js` | منطق الاهتمامات والحالة والمجالات والتقييم المختصر، والتحرير المعلن؛ عدم التقييم منفصل عن الصفر |
| `web/assets/explorer.js`, `demos.js`, `compass.js` | الرحلة والتجارب الأربع والحركة، وسياق رجوع متحقق منه، والتحقق النصي من المبلغ قبل التقريب العددي |
| `web/assets/js/logic.js` | الحسابات الأصلية للتقييم الموسع، و`parseJourney`/`exportJourney`؛ المرجع الوحيد للتحقق والترحيل والتعارض لرحلات v1–v3 |
| `web/assets/journey.js` | غلاف v4 حول المستكشف وملف v3 مستقل؛ يعيد استخدام المدقق القديم، ومعاينة/نسخة استرجاع/تحقق قراءة قبل اعتماد الحفظ |
| `web/assets/js/app.js`, `assessment.html` | التقييم الموسع الثانوي؛ الأهداف والفجوات والخطة والمقارنة وتقارير HTML القديمة |
| `tests/` | المصادر والتحليل والحفظ والواجهة الرئيسية والموسع والمحدث، بمخازن ومتصفحات معزولة |
| `app.py`, `labor_market/` | تحليل العاملين بلوحة Streamlit مستقلة؛ لا يدخل في اقتراح المجالات |

الواجهة ثابتة بوحدات ES دون إطار أو خطوة بناء. Python 3.13 وخادم المكتبة القياسية محليان؛ pandas للتحليل وStreamlit للوحة المنفصلة. `websockets` من المتطلبات الموجودة تستخدم لاختبار Edge عبر CDP. لا حسابات أو API لاستقبال إجابات المستخدم. الخط محلي مع ملف رخصة OFL.

## التشغيل والجدولة

```powershell
.\.venv\Scripts\python.exe -B -m compass launch
```

http://127.0.0.1:8620/ هو الأصل المعتمد. `--no-update` يعطل التحديث اختياريًا، و`--update-now` يفرض التحقق عند بدء المشغّل، و`--interval-hours` و`--retry-hours` و`--check-minutes` إعدادات محلية. لا تبدأ نسخة ثانية إذا كان المنفذ يعمل؛ المشغّل يرفض المنفذ المشغول ولا يوقف عملية أخرى. `compass serve` يشغّل الخادم وحده على الأصل نفسه.

- الافتراضي: 168 ساعة من آخر محاولة ناجحة؛ 12 ساعة بعد فشل/تحديث جزئي؛ فحص الموعد محليًا كل 30 دقيقة دون شبكة.
- هذا هو جدول النموذج المعتمد المنقول، وليس موعدًا أسبوعيًا ثابتًا في Task Scheduler. لم تتغير إعدادات Windows العامة.
- يعمل أثناء تشغيل المشغّل والحاسوب فقط؛ لا خدمة مستضافة دائمة أو تحديث لحظي.
- ملفات المصادر: `data/sources/`. النشر: `web/published/`. نسخة fallback: `web/data/`. السجلات والموعد: `runtime/`.
- تُبنى البيانات إلى staging وتُفحص البيانات والبيان قبل نقل الجيل واعتماده ذريًا. تبقى النسخ السابقة عند فشل أي مرحلة؛ الملفات القديمة المسطحة تظل صالحة للقراءة.
- المؤشر يعرض الإصدار وتاريخ الملف والتحقق، ويفصل إطار المهارات عن مصادر السوق غير المستخدمة في ترتيب المجالات.
- الفترات الجديدة والتعارضات والمراجعات التي تختلف عن المعتمد تظهر للمراجعة البشرية. تغيير النسخ المعتمدة أو نقل الأدوار اليدوي عند تغير بصمة المصدر يحتاج مهمة منفصلة.

## حماية التقدم

المفتاح `compassExplorer.v1` وتفضيل `compassExplorer.motion` لم يتغيرا. التقييم الموسع `compass.profile` مستقل؛ لا يصير تقييمًا مختصرًا أو إجابات اهتمام. الملف v4 يضم سجلين واضحين، والاستعادة لا تتم إلا بعد التحقق الكامل والمعاينة والتأكيد. النسخة السابقة تُحفظ قبل الكتابة وتُراجع القراءة بعدها. السجل القديم v1/v2 يرحّل فقط عند فتح التقييم الموسع، مع نسخة من القيم الأصلية؛ لا تحويل تلقائي من الصفحة الرئيسية. التخزين على 8502 أصل مستقل؛ ينقل المستخدم ملفًا صادرًا منه، ولا نقرأ ملفه الشخصي أو نعدله.

التفاصيل وحدود اختلاف إصدار الإطار في [JOURNEY-FILE.md](JOURNEY-FILE.md).

## التحقق والحقوق

`python -m compass verify --quick` للمستكشف والمحدث والحفظ، و`--deep` لمجموعة `tests/` كاملة مرة واحدة. المتصفحات والملفات وهمية ومعزولة. نتائج الدمج الفعلية في [RELEASE-INTEGRATION.md](RELEASE-INTEGRATION.md)، وهي تحقق بواسطة المنفذ نفسه.

إذن إعادة الاستخدام العام لأصول المهارات غير محسوم؛ المصادر والبيانات المشتقة واللقطات خارج Git، وهذا لا يمنح إذن نشر. سجل أدلة الحقوق لكل مصدر في [PUBLICATION-READINESS.md](PUBLICATION-READINESS.md) (الدليل الكامل SOURCES-VERIFIED.md محفوظ محليًا). لم يُنشر التطبيق. أعداد العاملين ليست شواغر أو طلبًا على مهنة أو ملاءمة فردية.

التحسينات المؤجلة للإصدار التالي: اختبار استخدام فعلي، قارئ شاشة، وتفاصيل بصرية من ملاحظات عبدالله. لا توسع قطاعي أو تصميم جديد في الإصدار الأول.
